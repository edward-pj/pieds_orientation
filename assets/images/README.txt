# PIEDS Logo Customization

To use your own logo:
1. Save your logo file as `logo.png` (or `logo.svg`).
2. Place it right here in this folder: `assets/images/logo.png`.
3. The website will automatically detect and display it at the top of the page.

If no custom `logo.png` is placed here, the website automatically displays the sleek vector `logo.svg` (PIEDS BITS Pilani).
